TROUBLESHOOTING QUICK REFERENCE

Issue: "Element not found"

Issue: Login fails
  Fix: Verify email/password correct (try manual login first)

Issue: Slow execution (>5 minutes)
  Fix: Increase delays in random.uniform(2, 5)

Issue: Platform detection / account bans
  Fix: Use longer delays, residential proxies, different accounts

Issue: Backlinks not indexed
  Fix: Wait 3-30 days (normal), improve content quality

Issue: Script errors/crashes
  Fix: Check Python 3.8+, reinstall dependencies
