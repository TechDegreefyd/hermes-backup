## 📞 SUPPORT & TROUBLESHOOTING

### Common Issues & Solutions
```
❌ "Element not found" error
   → Update CSS selectors in browser_automation_backlink.py
   
❌ Login failures
   → Verify email/password correct
   → Try manual login first
   → Check if platform changed login flow
   
❌ Slow execution (>15 minutes)
   → Increase delays in random.uniform(2, 5)
   → Check internet speed
   → Verify no platform rate limiting
   
❌ Platform detection / account bans
   → Use longer delays (5-10 seconds instead of 2-5)
   → Enable residential proxies
   → Create new accounts
   → Reduce daily submissions per platform
   
❌ Backlinks not indexed
   → Wait 3-30 days (normal for Web 2.0)
   → Improve content quality
   → Check Google Search Console for crawl errors
   → Verify backlinks are actually live
   
❌ Script crashes
   → Check Python 3.8+ installed
   → Reinstall dependencies: pip install -r requirements.txt
   → Check error logs for stack trace
   → Run debug report: python /workspace/scripts/debug_report.py
```
